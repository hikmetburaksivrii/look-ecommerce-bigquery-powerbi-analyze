**🏠 Project Overview:** TheLook Is A Fictitious E-Commerce Fashion Website Developed By The Looker Team. The Dataset Contains Information About Customers, Products, Orders, Inventory, Logistics, Web Events And Digital Marketing Campaigns. This Synthetic Dataset Is Provided For Industry Professionals To Explore, Test And Evaluate Data Analysis Use Cases.

In This Analysis, The Main Focus Is Sales Performance. The Analysis Examines Changes In Sales Across Product Categories Over Time, The Top-Selling Products And Their Contribution To Total Revenue As Well As Seasonal Patterns In Sales Data. The Analysis Covers Two Main Cases: Product Performance Evaluation And Seasonal Trends Analysis.

**🔄 Project Workflow:** The Workflow Started With Exploring And Validating The Data In Google BigQuery Using SQL Queries. Since Most Of The Exploratory Data Analysis Could Be Performed Directly In Power BI, BigQuery Was Mainly Used To Check For Outliers, Identify Potential Logical Inconsistencies And Validate Relationships Between Tables Within The Dataset.

The Data Was Then Processed In Power BI Using Power Query For Data Cleaning And Transformation. After The Data Preparation Stage, The Required DAX Calculations Were Created And Organized In A Separate Measure Table For Better Management And Organization.

The Final Dashboard Includes Overall Sales Performance Scorecards, Top 10 And Bottom 10 Sales Quantities By Category And Product, Top 10 And Bottom 10 Gross Profit Values By Category And Product, Average Inventory Age And Seasonal Trends In Both Sales Quantity And Gross Profit.

🤖 Technologies Used: Google BigQuery | Power BI 🤖
